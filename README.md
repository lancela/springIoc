# Spring IoC 学习项目

本项目用于学习和实践 Spring 的核心功能，以及 Spring 与 JDBC、MySQL 的整合。通过逐步实现数据访问和业务操作，理解依赖注入、AOP 和事务管理在实际项目中的作用。

## 学习内容

| 知识点 | 掌握内容 |
| --- | --- |
| IoC / DI | 使用 Spring 管理对象，并通过依赖注入组织组件之间的关系 |
| Bean 生命周期 | 理解 Bean 的创建、初始化和销毁过程 |
| AOP | 使用面向切面编程实现日志记录、异常处理和耗时统计 |
| JDBC | 使用 JDBC 连接 MySQL 并执行数据库操作 |
| CRUD | 实现数据的新增、查询、修改和删除 |
| 事务 | 使用 `@Transactional` 管理事务，理解事务的基本行为 |
| 多 DAO 业务 | 在一个事务中管理多个 DAO 的数据库操作，保证业务操作的一致性 |

## 项目目标

- 熟悉 Spring 容器管理 Bean 的基本方式。
- 理解从 DAO 数据访问到业务层调用的基本流程。
- 掌握 JDBC CRUD 操作及 Spring 事务管理的基础用法。
- 通过多 DAO 场景理解事务如何覆盖一组相关的数据库操作。
